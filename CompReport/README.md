💕 This Web app works for Company Report generation for TPD file based on the material generated by Osiris Data.

**Available at: https://c-base-generator.streamlit.app/** 

For convenience, the application omitted several steps for traditional C-Base App. You are only required to directly imput your excel into the website and imput the latest year for the review duration (e.g. 2024 if the data involved is 2022-2024).

The uploaded excel should be a BVD raw data base:
1. with a sheet name of **"Raw Data"** (standard name) or **"result"** (default sheetname); and
2. the first column (row number) must be *removed*.

💕 Hope this web App facilidate your work!
